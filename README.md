# MediaTracker

Вебзастосунок для ведення персонального обліку медіаконтенту (книг, фільмів, серіалів), написання рецензій та ведення списків переглянутого й запланованого.

## Стек технологій
- **Backend:** Python 3, Flask, Flask-SQLAlchemy, Flask-Login
- **Database:** SQLite
- **Frontend:** HTML5, Jinja2, Tailwind CSS
- **Testing:** pytest
